Missing values

Today this is two tabs — Data Completeness and Missing per Chunk — over three rows. The Titanic report has one chunk, so the second tab is a single full-width block per column: a tab that hides nothing behind a click. Both options below keep the per-chunk data, which is the genuinely valuable part for streaming, and drop the tabs.

PRO

Each encoding answers one question, so neither is ambiguous at forty chunks. The chunk strip is where streaming earns its keep — a column that is fine early and empty later is a pipeline problem, and this is the only place in the report that shows it.

CON

Four columns is too many for 390px, so mobile has to stack the strip under the row — a second layout. And at one chunk the strip is a single flat block, which looks like a bug until you read the footnote.

What I'd do

Correlations: 8a for the empty state regardless, since it is what most reports show. Then 8b as the default view and 8c only above 640px with ten or fewer numeric columns.

Missing values: 8d when the report has one chunk, 8e when it has more than one. That is the same conditional you already have between the two correlation views, and it means neither layout is ever shown in the case that makes it look broken.
